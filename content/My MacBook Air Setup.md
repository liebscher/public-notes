1. Install Homebrew
2. Install Git
	1. Configure `git`
3. Install Software: `brew install --cask arc obsidian zotero raycast rstudio miniconda tidal`
4. `brew install node@24` ffmpeg yt-dlp ocrmypdf imagemagick libjpeg`
5. Arc setup
	1. Install Apple iCloud Password extension
6. Clean up dock
7. Set up iMessage
8. Add Obsidian Web Clipper to Arc
9. Set up Obsidian (inspired by [Steph Ango](https://stephango.com/vault))
10. `brew install r`
	1. [Install Rosetta](https://docs.posit.co/ide/desktop-pro/getting_started/installation.html#apple-silicon-mac-m1m2): `/usr/sbin/softwareupdate --install-rosetta`
11. Install Docker
