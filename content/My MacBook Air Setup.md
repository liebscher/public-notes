When I got a new laptop, I was inspired by some posts I found online documenting how they had customized their machine for their use cases. Here is an abbreviated version of my own.

1. Install Homebrew
2. Install Git
	1. Configure `git`
3. `brew install --cask arc obsidian zotero raycast rstudio miniconda tidal r`
	1. For R, [install Rosetta](https://docs.posit.co/ide/desktop-pro/getting_started/installation.html#apple-silicon-mac-m1m2): `/usr/sbin/softwareupdate --install-rosetta`
4. `brew install node@24 ffmpeg yt-dlp ocrmypdf imagemagick libjpeg`
5. Install Docker
6. Set up and personalize Arc
	1. Install Apple iCloud Password extension
	2. Install Obsidian Web Clipper extension
7. Clean up the dock
8. Set up iMessage
9. Set up and personalize Obsidian (inspired by [Steph Ango](https://stephango.com/vault))
